## Closing the Gap: From 55.35 ms to 4.29 ms P99

When the peer review in `03-review.md` challenged the original self-report, it established the foundational invariant for Project Genesis:

> **Claims are measured, not asserted.** Every number in the README is produced by a committed script, on recorded hardware, and can be regenerated by anyone with one command. If a target is missed, the README says so.

For versions `v0.1.0` through `v0.3.1`, the README said so. 

While Genesis passed 5 of the 6 empirical verification gates—sustaining over 277,000 lines/sec throughput, maintaining a strict 293 MB heap ceiling, holding 10,000 idle TCP connections simultaneously, detecting zero data races under `-race`, and matching 100% of randomized oracle queries—the **P99 Read Query Latency gate ($< 5.0\text{ ms}$)** was marked with a red status badge:
- **Measured Result:** `55.35 ms`
- **Status:** ❌ **MISSED TARGET**

The bottleneck was real: under a 50-client unthrottled TCP flood, partition read-lock contention on active buckets and runtime garbage collection mark pauses during partition eviction caused tail query latencies to spike by an order of magnitude above the challenge ceiling.

---

## The Engineering Overhaul (`v0.4.0`)

To conquer the last remaining challenge gate without compromising any invariant (stdlib-only, zero dependencies, zero egress), `v0.4.0` re-architected the storage and indexing tier:

1. **8-Way Sharded Partitions & Sealed Micro-Segments (`internal/index`):**
   - Active 5-second time partitions are split across 8 independent shards.
   - Incoming records seal into immutable 4,096-entry micro-segments (`partChunk`) backed by flat `[]parser.LogEntry` slices and pre-sorted inverted posting lists (`byService`, `byLevel`, `bySvcLevel`).
   - Query threads read sealed micro-segments without holding write locks on the active ingest lane.

2. **Zero-Pointer (`noscan`) SkipList Arena (`internal/index/skiplist.go`):**
   - Replaced pointer-heavy heap node allocations with an index-addressed `[]skipNode` arena containing zero pointers.
   - Completely eliminates Go runtime GC mark scanning and write barriers across evicted segments.

3. **Buffer Reuse & Cooperative Backpressure (`internal/engine`, `internal/parser`, `internal/cli`):**
   - Implemented `sync.Pool` reuse for raw ingestion byte slices and HTTP query JSON serializers.
   - Single-backing-string slicing for parsed fields (`TraceID`, `Message`).
   - Per-connection golden-ratio jittered microsecond backoff on TCP queue saturation, engaging kernel flow control cleanly.
